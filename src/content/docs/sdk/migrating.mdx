The release that follows `0.6.0-beta.1` targets core `fa7b92d`. The prover's request shape and exports are unchanged. The contract surface, `join`, the adapter contract and the leaves passed to a spend all changed.

## Changes

| # | Change | Action |
| --- | --- | --- |
| 1 | `join`'s `managerSide` returns `{ ukx, signer, deadline, signature }`, signed over `registerUserDigest(reserve, leaf, signer, deadline)`, EIP-712 version 3 | Sign the new digest and return the four fields |
| 2 | `setRegistrar()` is removed | The Reserve admin calls `grantPermission(reserve, "USERS", registrar)` |
| 3 | `setVerifier()` is removed | The verifier changes through a 7-day owner timelock, `proposeVerifier` and `executeVerifierUpdate` in `ABIS.Chamber`, outside the client |
| 4 | `setReserveScreener()` goes to the Reserve and needs `SCREENING` | Call it as a holder of `SCREENING` |
| 5 | Adapters return `receipt.logs` or the deposit's `(noteHash, depositId)` as `result` | Return logs from `sendTransaction`. Otherwise `deposit` stops after the approve |
| 6 | `SpendOpts.state.txLeaves` is the leaves of the input notes' one transaction tree | Pass `txTreeLeaves(treeId)`, or omit `state` |
| 7 | With fetched state, `spend` spends only notes it can find in a tree | Give each note a `hash` or a `txIndex` |
| 8 | `getEvents` also serves `UserRemoved`, and every user event of a Reserve with members | Return all of them |
| 9 | The contents of `CORE_ABI` and `SCREENING_ABI` changed. `SCREENING_ABI` gains `setDepositRefundTo` and `DepositRefundToSet`, and `DepositQueued` carries `refundTo` | Rebuild any `parseAbi(CORE_ABI)` and event decoding from the new exports |
| 10 | Reclaiming a pending deposit is the depositor's alone and refunds the depositor. `refundTo` is paid only after a rejection | Update any flow that reclaimed a pending deposit as `refundTo` |
| 11 | `revokeRegistration(reserve, leaf)` takes no deadline and voids every signature for the leaf | Drop the deadline argument |

New in this release: `grantPermission`, `revokePermission`, `transferAdmin`, `acceptAdmin`, `hasPermission`, `setAssetMinDeposit`, `removeUser`, `revokeRegistration`, `setDepositRefundTo`, `txTreeLeaves`, `registeredUserLeaves`, `RESERVE_ROLES` and `ManagerApproval`. `Note` gains `txIndex`, `DepositOpts` gains `refundTo`, `pick` takes a third argument `txTreeCapacity`, and `plan` takes `txTreeCapacity` and returns `txTree`.

## join

Before, the key holder returned the key exchange and a signature over the leaf. Now it returns who signed and until when, and the digest binds more.

```ts
import type { Hex, ManagerApproval } from "@mistcash/sdk";

declare const ukx: string;
declare const signer: Hex;
declare const deadline: bigint;
declare const signature: Hex;

// 0.6.0-beta.1
const before = { ukx, signature };

// Next release
const after: ManagerApproval = { ukx, signer, deadline, signature };
console.log(before, after);
```

[Joining a Reserve](/sdk/joining-a-reserve/) has the full key holder code and what the digest binds.

## Setting up a Reserve

Before, `setRegistrar(reserve)` pointed a Reserve at a registrar. Now the registrar is an account with `USERS`, like any signer.

```ts
import { MistClient, type AddressBook, type Hex } from "@mistcash/sdk";

declare const client: MistClient;
declare const book: AddressBook;
declare const reserve: Hex;
declare const screener: Hex;

await client.grantPermission(reserve, "USERS", book.registrar);
await client.setAssetMinDeposit(reserve, book.token, 1n);
await client.setReserveScreener(reserve, screener);
```

## Adapters

```ts
import type { ChainAdapter } from "@mistcash/sdk";
import type { TransactionReceipt } from "viem";

declare function submit(data: `0x${string}`): Promise<TransactionReceipt>;

const sendTransaction: ChainAdapter["sendTransaction"] = async (tx) => {
  const receipt = await submit(tx.data);
  // Next release: logs are required
  return { hash: receipt.transactionHash, receipt: { transactionHash: receipt.transactionHash, status: receipt.status, logs: receipt.logs } };
};
console.log(sendTransaction);
```

[Client and address book](/sdk/client/) lists what each adapter member must return.
