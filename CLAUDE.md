# CLAUDE.md — MIST.cash Docs

Astro Starlight site for MIST.cash, restyled to the landing design
(`landing/DESIGN.md` is the source of truth). Content describes the EVM
protocol: the gnark Groth16 circuit, the Solidity contracts and
`@mistcash/sdk`. `spec/` in the root repo is the document of record: a spec
claim beats marketing copy.

## Commands

- `npm run dev` — local dev server with HMR
- `npm run check` — `astro check`
- `npm run copyrules` — holds every page to the MIST copy rules (prose only)
- `npm run build` — static site to `dist/`
- `npm run linkcheck` — internal link check, after a build
- `npm run preview` — preview the production build

CI runs check, copyrules, build and linkcheck. All four must be green.

## Adding a page

Drop an `.mdx` file under `src/content/docs/circuits/`, `contracts/` or `sdk/`.
The sidebar is autogenerated per directory; order with
`sidebar: { order: N }` in frontmatter (each section's `index.mdx` is order 0
and labelled Overview). Link the new page from its section's index.

## Design rules that bind this repo

- Three colours only: midnight, azure, coral, plus tints of them. No green or
  red for status: say what happened in words.
- Square corners (2px on controls), 1px rules, no shadow, no blur, no gradient.
- Coral is the one action and at most one marker per view. Never a coral word.
- Josefin Sans for headings, Sen for text, system monospace for code.
- Diagrams use the grammar in `src/styles/diagram.css` and the components in
  `src/components/diagrams/`, and must read in both themes at 390px.
- Run `npm run copyrules` before pushing: no em-dashes, no `token`, no chain
  names, no hype, no "test".
