# MIST.cash docs

Astro + Starlight documentation site.

```bash
npm ci
npm run dev        # local dev server
npm run check      # astro check
npm run build      # static build to dist/
npm run linkcheck  # internal link check (after build)
```

Node version is pinned in `.nvmrc`.

## Where this is deployed

Production URL: https://docs.mist.cash (referenced from the MIST landing site).

Hosting: believed to be Vercel (an earlier PR showed a Vercel check), but this
repo contains no hosting config. Unknown, maintainer to fill: project/account,
build settings, and domain setup.
